# Dewa AI (FloodAI) — Project Structure

> **Status:** the former `app/` package was **flattened to top-level** on branch
> `refactor/flatten-app-package`. Every `app.<sub>` import became `<sub>`, the
> entrypoint is now `uvicorn api.main:app`, and the bundled runtime JSON moved
> from `app/data/` to `data/bundled/`. Verified: `--collect-only` imports all
> 506 tests with zero errors; 303 pure (no-I/O) tests pass.

## Import / path migration (applied)
| Before | After |
|---|---|
| `from app.api.main import …` | `from api.main import …` |
| `import app.services.X` | `import services.X` |
| `"app.api.main" in sys.modules` (scraper) | `"api.main" in sys.modules` |
| `parents[2]` (in moved files → project root) | `parents[1]` |
| `_PROJECT_ROOT / "app" / "data" / …` (locators) | `… / "data" / "bundled" / …` |
| `parents[1] / "data" /` (bnpb_context bundled files) | `parents[1] / "data" / "bundled" /` |
| `uvicorn app.api.main:app` (README) | `uvicorn api.main:app` |
| `app/data/*.json` | `data/bundled/*.json` |
| `app/.env` | deleted (root `.env` is authoritative) |

## Scope of change
- **98** Python files rewritten for imports/strings; **21** files had filesystem
  path references fixed (per-file `parents[N]` review, not blind sed).
- `services/awlr_threshold_fetcher` & `pintu_air_fetcher` read `data/raw/`;
  `bnpb_jakarta_mapper`/`drift_monitor`/`utils.paths` read top-level `data/`/`scripts/`
  (parents decremented only) — only the 5 locators + build scripts + bnpb_context
  bundled paths repoint to `data/bundled/`.

## Verification
- `python -m pytest --collect-only` → **506 collected, 0 import errors**.
- Pure no-I/O subset (unit + locator/decision/fetcher tests) → **303 passed**.
- Environmental-only non-passes (unchanged from `main`, require external infra):
  `test_dashboard_route` (live DB health query), `test_agentic_explain`
  (Anthropic API), `test_psycopg2_connection` / `test_migration_runner` (live DB).

## Migration Notes
- Run from repo root: `uvicorn api.main:app --reload`.
- Tests resolve top-level packages via repo-root on `sys.path` (same as before).
- `data/bundled/` is regenerated by `scripts/build_*.py` (now writing there).
